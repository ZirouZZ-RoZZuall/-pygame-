# Fast Clicker
## Общее описание:
1. Мини игра где надо успеть набрать очки за отведённое время, нажимая на карточки с надписью "CLICK".
2. Частота кадров (fps) 40.
3. Количество очков нужное для победы - 5.
4. Скорость с которой меняется "правильная" карточка - 15 кадров. (примерно 0.375 секунд)
5. При нажатии на правильную карточку ( на которой написано "CLICK") она загорается зелёным на 1 кадр и ваш счёт увеличивается на 1.
6. При нажатии на неправильную карточку ( которя будет выглядить как прямоугольник с сплошным оранжевым цветом) она загорается красным на 1 кадр и ваш счёт уменьшается на 1.
